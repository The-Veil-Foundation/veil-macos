FeaturesВозможности

Modern protocols

Современные протоколы

VLESS, VMess, Trojan and Shadowsocks with Reality and TLS over tcp, ws, grpc, http and xhttp, including xtls-rprx-vision and post-quantum encryption. Hysteria2, TUIC, WireGuard and AnyTLS run on a bundled sing-box core.

VLESS, VMess, Trojan и Shadowsocks с Reality и TLS поверх tcp, ws, grpc, http и xhttp, включая xtls-rprx-vision и постквантовое шифрование. Hysteria2, TUIC, WireGuard и AnyTLS работают на встроенном ядре sing-box.

Two tunnel modes

Два режима туннеля

System proxy for browsers, or a full-device TUN that routes every app: Telegram, the terminal, games, UDP.

Системный прокси для браузеров или полный TUN для всех приложений: Telegram, терминал, игры, UDP.

Subscriptions

Подписки

Import subscription URLs as profile groups. Traffic, expiry and description come from standard headers, and profiles update themselves.

Подписки импортируются как группы профилей. Трафик, срок и описание берутся из стандартных заголовков, профили обновляются сами.

Professional routing

Профессиональная маршрутизация

Presets and a full rule editor with geosite and geoip databases downloaded from GitHub, in the style of v2rayN.

Пресеты и полный редактор правил с базами geosite и geoip, загружаемыми с GitHub, как в v2rayN.

Instant switching

Мгновенное переключение

Changing servers keeps the transport up and re-pins the route. It takes under a second and never asks for a password.

При смене сервера транспорт остаётся поднятым, меняется только маршрут. Меньше секунды и без запроса пароля.

Latency testing

Тест задержки

TCP-connect ping per server or group, bypassing the tunnel while TUN is on. Sort by ping and hide dead servers.

TCP-пинг по серверу или группе в обход туннеля при включённом TUN. Сортировка по пингу и фильтр живых серверов.

QR import and export

QR-импорт и экспорт

Show any server as a QR code or save it as PNG. Add servers by scanning a QR with the camera or from an image.

Покажите любой сервер как QR-код или сохраните его в PNG. Добавляйте серверы, сканируя QR камерой или из картинки.

Ad and tracker blocking

Блокировка рекламы

One switch drops ads and trackers at the routing layer with geosite:category-ads-all.

Один переключатель отбрасывает рекламу и трекеры на уровне маршрутизации через geosite:category-ads-all.

Menu bar control

Управление из меню-бара

Connect, disconnect and switch servers without opening the window. Close to tray and connect on launch.

Подключение, отключение и смена сервера без открытия окна. Сворачивание в трей и автоподключение при запуске.

12 languages

12 языков

English, Русский, 中文, Español, हिन्दी, العربية, Français, Português, Deutsch, 日本語, Indonesia, Türkçe.

Safe by default

Безопасно по умолчанию

Routes and DNS are restored on quit, and a crashed session is recovered on the next launch, so you are never left offline.

Маршруты и DNS восстанавливаются при выходе, а упавшая сессия чинится при следующем запуске — без сети вы не останетесь.

RoutingМаршрутизация

Presets, downloadable geo databases and a full ordered rule editor.

Пресеты, загружаемые geo-базы и полный редактор правил с порядком.

Getting startedКак начать

  1. Add servers

    Добавьте серверы

    Import a subscription URL, paste vless://, vmess://, trojan://, ss://, hysteria2://, tuic:// or wireguard:// links, or scan a QR code.

    Импортируйте подписку, вставьте ссылки vless://, vmess://, trojan://, ss://, hysteria2://, tuic:// или wireguard://, либо отсканируйте QR-код.

  2. Pick a mode

    Выберите режим

    Proxy for browsers, or TUN for the whole device. TUN installs its helper once.

    Proxy для браузеров или TUN для всего устройства. TUN ставит хелпер один раз.

  3. Connect

    Подключитесь

    Click a server. Switch at any time from the window or the menu bar.

    Нажмите на сервер. Переключайтесь в любой момент из окна или меню-бара.

Приложение для iPhone уже написано и собирается. iOS не запустит его без членства Apple за $99.

A VPN tunnel on iOS needs the Network Extension entitlement, and Apple only issues it with a paid Developer Program membership ($99 a year). Raising that is the only thing between the code and a build you can install.

VPN-туннелю на iOS нужно разрешение Network Extension, а Apple выдаёт его только с платным членством в Developer Program ($99 в год). Собрать эту сумму — единственное, что отделяет код от сборки, которую можно поставить.
